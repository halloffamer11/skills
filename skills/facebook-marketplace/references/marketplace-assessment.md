# Marketplace assessment

Compare the prospective listing with local Marketplace competition. The result
supports a recommendation; it never replaces seller confirmation or licenses an
unsupported claim.

Use a signed-in browser for local comparison when one is available, since
location, listing detail, and recency matter. Without access, say so, use
supplied observations or other market evidence, and never imply a search you
did not run.

## Scope and queries

Read the seller area from project configuration or the record, and record the
postal area or city, radius, date, and any visibility limits you actually used.
Do not assume a default radius is the seller's market.

Search a compact set of variants: exact model and variant; shortened model name
or number; family or generation name; common abbreviations; category terms a
seller might use instead; likely misspellings and spacing changes. Keep the
queries with the observations so coverage can be judged.

## Observation table

One row per comparable listing in the record. Record only what is visible or
reasonably inferable; otherwise `unknown`.

| Field | Record |
| --- | --- |
| Reference | Link or identifier, query used, date observed |
| Asking price | Displayed price and currency, and whether it looks negotiable. An asking price is not a sale price. |
| Price change | A displayed reduction or prior price, else unknown |
| Condition | Seller's stated condition and visible evidence, kept apart |
| Variant | Model, generation, color, size, SKU, or unknown |
| Included items | Listed or visible components; unshown items unknown |
| Location | Displayed location and distance |
| Photos | Order, coverage, clarity, defect disclosure (facts, not motive) |
| Title | How precisely it identifies the item |
| Description | Whether it covers identity, condition, contents, testing, limits, handoff |
| Recency | Displayed age, else unknown; age is not availability |
| Seller type | Individual, business-like, or unknown, only when visible |

## Price evidence

Treat Marketplace prices as asking prices unless reliable completed-sale
evidence is visible. Record any completed-sale evidence separately with its
source, date, item match, condition, and limits, or say none exists.

When the sample is sparse, widen in deliberate steps: more query variants, a
larger radius, then other evidence such as credible sold-item sources or
replacement prices. Record what each expansion costs: a wider area is less
convenient for buyers, other platforms have other fees and behavior, and a weak
item match cannot value the seller's variant.

For time-sensitive categories (seasonal goods, weather-driven demand, school or
holiday timing), record the current local demand signal with its source and
date, and let it shape price direction and urgency.

## Judgment

Compare like with like: variant, condition evidence, tests, included items,
visible wear, location and handoff convenience, recency. Then say whether the
market leaves room for a better-supported listing or whether more work is
unlikely to pay off, with the evidence and its limits rather than false
precision.

Look for gaps the seller can close truthfully with their own evidence: exact
identification where competitors are vague, a readable model label, clear
condition photos and honest defects, real test results, an explicit
included-items list, a factual answer to a recurring objection, a better photo
order, a convenience the seller actually offers. Never copy a competitor's
text, photos, or tactics, and never use fake urgency or scarcity, misleading
anchors, hidden defects, or competitor errors.

## Output

Return a compact, evidence-labelled assessment: market observations (scope,
asking prices, matches, differences); limitations (sample size, date, area,
unresolved variants, completed-sale evidence or its absence); pricing
implications; title and copy implications; the one photo or test that would
most reduce uncertainty; and the ethical opportunities with a judgment on
whether they are worth the effort.
