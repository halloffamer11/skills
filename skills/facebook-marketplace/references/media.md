# Media

Any tool or format that achieves these outcomes is fine.

## Inspect

Inventory every photo and video. Note duplicates, sharpness, lighting,
orientation, framing, reflections, personal information, exposed serial
numbers, and coverage of visible defects. Record what each file supports.

- Before using a numeric value read from a label, inspect it at original
  resolution and recheck the transcription against the image.
- Apply the file's embedded (EXIF) orientation before cropping or measuring; a
  crop computed on un-oriented pixels lands on the wrong region.

## Derive

Derive a file only when it helps viewing or compatibility: conversion,
rotation, crop, exposure correction, compression, normalization. Keep
originals unchanged and trace each derivative to its source and
transformation. Never derive a file that hides damage, removes meaningful
context, or changes how the product looks.

## Select

Order for easy, truthful evaluation: a clear hero image, overall condition,
important angles, functional components, included accessories, safe model
evidence, then honest defect disclosure. Prefer a smaller clear set over
repetition. Keep enough model evidence to support identification without
publishing personal information or unnecessary serial numbers. A video may serve
as evidence or a source of stills; publishing one is never required.

## Ask for more only when it matters

Recommend another photo or test only when it resolves a consequential buyer
uncertainty found in research, such as a model-confusing label, a needed
accessory, a visible defect, or a feature that changes value or safe use. Name
the uncertainty and the evidence that would resolve it. Never ask for extra
work just for polish.

## Record

In the listing record, write the source and derived directories, the selected
files in display order with a short evidence note each, and rejection notes
(duplicate, weak framing, privacy risk, ambiguity, uncovered limitation).
